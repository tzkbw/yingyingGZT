# 莹莹的工作台

专属私人工作台 PWA 应用，支持添加到手机桌面，离线可用。

## 功能

- 时间概览与今日运势
- 经期记录与症状备注
- 运动计划打卡
- 穿搭造型评分
- 自定义头像与用户名

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库
2. 把本仓库所有文件推送到 `main` 分支
3. 进入仓库 Settings → Pages → Source 选择 `main` 分支
4. 等待几分钟后，访问 `https://你的用户名.github.io/仓库名/`

## 添加到手机桌面

### iPhone / iPad（Safari）

1. 用 Safari 打开网站
2. 点击底部「分享」按钮
3. 选择「添加到主屏幕」
4. 返回桌面，点击「莹莹工作台」图标即可全屏使用

### Android（Chrome）

1. 用 Chrome 打开网站
2. 点击右上角菜单 → 「添加到主屏幕」
3. 返回桌面，点击图标即可全屏使用

## 离线使用

应用包含 Service Worker，首次加载后核心资源会缓存到本地，断网也能继续使用。
